## Slide 2 — Why generate spreadsheets?
- So far we've *analysed* data with NumPy. But the people we work for rarely
  want a Python console — they want a **spreadsheet** they can open, sort and
  share.
- Python can build `.xlsx` files for us automatically: same report, every week,
  no copy-paste, no human error.
- We'll use a library called **openpyxl**, the standard tool for reading and
  writing Excel files in Python.
- Like NumPy, it isn't in the standard library, so it must be installed (it's
  already in this project's `requirements.txt`):

```python
import openpyxl
```

---

## Slide 3 — Workbooks and worksheets
- An Excel file is a **Workbook**. Each workbook contains one or more
  **Worksheets** (the tabs at the bottom).
- We start by creating a workbook and grabbing its active sheet:

```python
from openpyxl import Workbook

wb = Workbook()          # a new, empty workbook
ws = wb.active           # the first (active) sheet
ws.title = "Players"     # name the tab

wb.save("report.xlsx")   # nothing is written to disk until you save
```

- **Output:** a file `report.xlsx` appears with one tab named *Players*.
- Note: `wb.save()` is the step beginners forget — until you call it, the file
  doesn't exist.

---

## Slide 4 — Writing into cells
- A cell is addressed exactly like in Excel: a **column letter** + a **row
  number**, e.g. `A1`, `B2`.
- Two equivalent ways to write a value:

```python
ws["A1"] = "Name"               # by Excel reference
ws.cell(row=1, column=2, value="Height")   # by row/column number
```

- Use `["A1"]` when you know the exact cell; use `cell(row, column)` when you're
  **looping** and the position is calculated. (We'll need the second form on the
  next slide.)
- **Output (right):** screenshot of the sheet with `Name` in A1 and `Height` in B1.

---

## Slide 5 — Writing a header row
- Reports start with a header row. We can write a list of titles across row 1:

```python
headers = ["Name", "Height", "Weight", "Age"]

for column, title in enumerate(headers, start=1):
    ws.cell(row=1, column=column, value=title)
```

- `enumerate(headers, start=1)` gives us `(1, "Name")`, `(2, "Height")`, … so
  each title lands in the right column.
- **Output (right):** screenshot — row 1 filled with the four headers.

## Slide 6 — Writing real data
- Let's bring in the baseball dataset we analysed in Project 3 and write every
  player into the sheet:

```python
import pandas as pd

data = pd.read_csv("Module 4/data/baseball.csv")
data = data[["Name", "Height", "Weight", "Age"]]

for row in data.itertuples(index=False):
    ws.append(row)        # append adds a new row at the bottom
```

- `ws.append()` is the easiest way to add a whole row at a time — it writes the
  values left-to-right and moves to the next row automatically.
- **Output (right):** screenshot — header row plus hundreds of player rows.

## Slide 7 — Formulas vs. Python values
- A summary row can be produced two ways. We can let **Excel** do the maths by
  writing a formula as a string:

```python
ws["B1017"] = "=AVERAGE(B2:B1016)"   # Excel computes this when opened
```

- …or we can compute it **in Python** with NumPy and write the finished number:

```python
import numpy as np

avg_height = np.mean(data["Height"].to_numpy())
ws["C1017"] = avg_height              # a fixed value, already calculated
```

- Difference worth stressing: the **formula** recalculates if the data changes
  inside Excel; the **NumPy value** is frozen at the moment we wrote it.

## Slide 8 — Formatting cells
- A report should look like a report. openpyxl lets us style fonts, fills and
  column widths:

```python
from openpyxl.styles import Font, PatternFill

for cell in ws[1]:                    # ws[1] is the whole first row
    cell.font = Font(bold=True, color="FFFFFF")
    cell.fill = PatternFill("solid", fgColor="1F3864")

ws.column_dimensions["A"].width = 22  # widen the Name column
```

- **Output (right):** screenshot — bold white headers on a dark blue band, Name
  column wide enough to read.

---

## Slide 9 — Adding a chart
- openpyxl can draw native Excel charts. A scatter chart of height vs. weight
  ties straight back to the correlation we found in Project 3:

```python
from openpyxl.chart import ScatterChart, Reference, Series

chart = ScatterChart()
chart.title = "Height vs. Weight"

x = Reference(ws, min_col=2, min_row=2, max_row=1016)  # Height
y = Reference(ws, min_col=3, min_row=2, max_row=1016)  # Weight
chart.series.append(Series(y, x))

ws.add_chart(chart, "F2")             # place it anchored at cell F2
```

- **Output (right):** screenshot — the sheet with an embedded scatter chart;
  the upward cloud of points mirrors the 0.58 correlation from 4.1.3.

## Slide 10 — Reading a spreadsheet back
- Generating isn't the whole story — we can also **open** an existing workbook:

```python
from openpyxl import load_workbook

wb = load_workbook("report.xlsx")
ws = wb["Players"]

print(ws["A2"].value)     # read a single cell
print(ws.max_row, ws.max_column)
```

- Useful when a report needs *updating* rather than rebuilding from scratch.

## Slide 11 — The shortcut: pandas
- For a plain data dump with no formatting, pandas does it in one line:

```python
data.to_excel("quick_report.xlsx", index=False)
```

- Mention this so students know it exists — but the openpyxl approach is what
  gives us headers, formulas, styling and charts.
